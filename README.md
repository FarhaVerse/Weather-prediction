🌦️ Weather Prediction Using Machine Learning

📌 Project Overview

The Weather Prediction System is a Machine Learning project that predicts weather conditions based on different atmospheric and environmental features.

This project uses Machine Learning classification algorithms to analyze weather data and predict weather types such as Sunny, Rainy, Cloudy, and Snowy.

The main aim of this project is to understand how Machine Learning algorithms can be used for weather classification and prediction.

🎯 Project Objectives

- To analyze weather classification data.
- To perform data preprocessing and Exploratory Data Analysis (EDA).
- To implement different Machine Learning classification algorithms.
- To compare model accuracy and performance.
- To predict weather conditions based on user input.
- To develop an interactive application using Streamlit.

📂 Dataset Description

Dataset Name: Weather Classification Dataset

The dataset contains different weather-related features used to predict the weather type.

Target Variable: "Weather Type"

The system predicts the weather category based on the input features.

🤖 Machine Learning Algorithms

Four classification algorithms are implemented in this project:

1. Decision Tree Classifier
2. Random Forest Classifier
3. K-Nearest Neighbors (KNN)
4. Logistic Regression

The models are compared using accuracy scores to understand their performance.

Selected Model: Random Forest Classifier

The Random Forest model is used for the final weather prediction system.

📊 Model Evaluation

The following evaluation techniques are used:

- Accuracy Score
- Classification Report
- Confusion Matrix
- Model Accuracy Comparison

⚙️ Installation and Setup

Step 1: Clone the Repository

Step 2: Open the Project Folder

Step 3: Install Required Libraries
